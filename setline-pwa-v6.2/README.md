# Setline PWA v6.2

This update includes:
- A simple professional **S** app icon
- The Setline logo displayed on the dashboard
- A redesigned calorie-entry card that prevents food names, macros, calories, and action buttons from overlapping
- A new service-worker cache version so devices receive the update
- Existing v6.1 browser data remains intact

## Update the GitHub Pages site

1. Open the `Setline` repository.
2. Delete or replace the old files in the repository root.
3. Upload **all contents of this package**, keeping the `icons` folder.
4. Commit the changes.
5. Wait a few minutes, then open the live site and refresh it.

## Refresh an already installed app

Open Setline while online and refresh it once. If the old icon remains:
- Android: remove Setline from the home screen, clear the site's cached data in Chrome if necessary, then install it again.
- iPhone: remove the old home-screen shortcut, open the site in Safari, then use **Share → Add to Home Screen** again.

Workout and nutrition records continue using browser local storage and are not synced between devices.
