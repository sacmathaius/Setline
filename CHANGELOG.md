# Changelog

## 6.6.0 — August 5, 2026

### New
- React and Material UI interface rebuild
- Light, dark and system appearance modes
- Guided onboarding and weekly program setup
- Searchable Training Guide for RIR, RPE, AMRAP, drop sets, failure, supersets and deloads
- Explainable weekly muscle-region coaching report
- Unified progress hub and full in-app changelog

### Improved
- Faster workout logging and previous-set prefilling
- Nutrition day view, favourites, recent foods, templates and barcode workflow
- Responsive layouts for iPhone, Galaxy and desktop screens
- Completion, streak and save feedback with reduced-motion support

### Reliability
- Permanent `setline-data-v1` storage key retained
- Pre-migration backup, last-good backup and empty-overwrite guard
- Import now merges records rather than replacing them
- Service-worker update banner and rollback-friendly cache versioning
